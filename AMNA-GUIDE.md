# Amna ke liye project guide

## Website kholna
ZIP extract karo. Extracted folder mein `index.html` ko browser mein kholo. Home, Blog aur Contact links se pages khulenge. Contact page par aapka email aur GitHub profile diya gaya hai.

## Is example ko samajhna aur apna banana
Internship brief ke mutabiq kaam original hona chahiye aur AI learning, research aur ideation ke liye allowed hai. Yeh AI-assisted example hai; submission se pehle program se AI-generated code aur images ke istemal ki permission confirm karein. Apni writing, ideas aur changes lagayen aur har part samajh kar hi submit karein.

- Teen HTML pages hain. Har ek `css/style.css` ko use karta hai.
- Navigation mein `href` doosre page ki file kholta hai; `aria-current="page"` active page batata hai.
- CSS media query choti screen par columns ko ek ke neeche ek rakhti hai.
- Blog mein char cards hain; images `images` folder mein hain aur Notion AI se generate hui hain.
- Contact ka email clickable hai. Form message visitor ki email app mein tayyar karta hai; visitor ko wahan Send dabana hota hai. Device par email app configured hona zaroori hai; website khud email nahi bhejti.

## GitHub par upload
1. ZIP extract karo aur GitHub par login karo.
2. New repository banao: `tsg-webdev-p03-amna-pervez`, visibility **Public** rakho.
3. **Add file → Upload files** se extracted project folder ke andar ki files aur folders upload karo. ZIP ko as-is upload mat karo. `index.html` repository ke root mein ho.
4. **Commit changes** karo. Repository URL copy karo. Sirf profile link repository link nahi hota.
5. Repository mein **Settings → Pages → Build and deployment** mein `Deploy from a branch` select karo; apni default branch aur `/(root)` choose karke Save karo.
6. GitHub Pages ka actual live URL aane ka wait karo; phone aur desktop dono par test karo. Agar settings na milen to GitHub Help dekho.
7. `README.md` mein actual repository aur live website links add karo. Website update hone par naye screenshots aur apni recording lo.
