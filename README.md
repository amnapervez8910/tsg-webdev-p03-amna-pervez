# Amna's Journal

A responsive, three-page creative living blog by Amna Pervez.

## Links

- **Live website:** https://tsg-webdev-p03-amna-pervez.vercel.app/
- **GitHub repository:** https://github.com/amnapervez8910/tsg-webdev-p03-amna-pervez

## Pages

- **Home** — introduction and featured posts
- **Blog** — four post cards with images and previews
- **Contact** — contact details and a styled form

## Technologies

HTML5, CSS3 and JavaScript. All three pages use one shared CSS file.
The layout adapts to desktop and mobile screens.
